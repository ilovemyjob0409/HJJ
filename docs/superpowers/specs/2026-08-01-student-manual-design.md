# 學生帳號教學手冊 — 設計文件

日期：2026-08-01
狀態：已與使用者確認

## 目標

為 HJJ 系統的學生（與家長）製作一份操作教學手冊，含畫面截圖與逐步流程說明。

## 產出

- `學生帳號教學手冊.pdf`（A4 直式、中文排版、淺色模式截圖，適合列印與 LINE 傳送）

## 章節架構

1. 封面與簡介 — 系統用途、網址、建議用手機開啟
2. 登入系統 — 帳號密碼登入、深夜模式切換
3. 學生首頁導覽 — 集點卡摘要、補課須知、功能捷徑、我的班級、請假與插班紀錄、弈廳報名紀錄
4. 請假申請 — 選班級、選日期、填原因、送出後查詢紀錄
5. 申請補課 — 插班／一對一兩種流程、狀態說明、撤銷補課
6. 我的出席紀錄
7. 集點卡 — 一般／兌換專用點數、抽獎登記、兌換
8. 弈廳報名 — 查看場次、報名與取消
9. 活動專區 — 瀏覽活動、活動相簿
10. 常見問題（FAQ）

## 截圖方式

- 手機版截圖為主軸（375×812），關鍵頁面附電腦版（1280×800）全頁對照
- 使用本機開發環境＋示範資料（student@example.com／小明），不拍真實學生個資
- 截圖前先充實本機示範資料（請假、補課、點數、活動、弈廳場次）
- 一律淺色模式；深夜模式僅示範切換按鈕
- 截圖上以紅框標示要點擊的位置（Playwright 注入樣式後截圖）

## 呈現格式

每一步：步驟編號＋文字說明＋截圖（紅框標示操作點）。

## 製作方式

1. 啟動本機 dev server 與資料庫
2. 補足示範資料（僅新增，不修改既有資料）
3. Playwright 腳本自動登入學生帳號、逐頁截圖存檔
4. HTML 排版（內嵌截圖）→ Chromium 轉 A4 PDF
5. 逐頁檢查 PDF 後交付
