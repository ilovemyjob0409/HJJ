# 收費模組設計（2026-08-28 定案）

## 目標與範圍

- 解決兩件事：**應收金額計算**（帳單產生）＋**繳費登記**（錢的帳本）。
- **不做**線上金流（家長照舊線下繳：現金／轉帳）。
- 涵蓋：一般班級（圍棋、英數科目的班——按堂計價）＋個別輔導 MPM&PLUS（月費級距）。
- **排除**：弈廳（已有票券購買／扣堂帳本，現場收費維持現狀）。

## 計費模型

### 一般班級（按堂計價）

1. **區間堂數**：收費區間內，照班級的每週上課日展開所有日期，扣掉落在「停課日曆」的日子。
2. **上期剩餘折抵**：折抵堂數 ＝ min(上期剩餘堂數, 折抵上限)。折抵上限存在收費設定，**預設 2 堂**，可調。超過上限的剩餘堂數**不折錢、不作廢**——保留在堂數餘額，新一期繼續用。
3. **計費堂數** ＝ 區間堂數 − 折抵堂數。
4. **單價** ＝ 學生覆寫價 ?? 班級單價。班級未設價 → 草稿該列金額空白＋紅字提醒，**補價前不能定案**。
5. **金額** ＝ 計費堂數 × 單價，整數元。

### 個別輔導（月費級距）

1. **級距表**（後台可維護）：每列「名稱、每週堂數、月費」。預設兩列：一週兩堂 3000、一週一堂 1500。
2. 每個個別輔導報名指定使用的級距。選「一週一堂」時 UI 提示把該生月額度改成 4（**額度與收費不強制連動**，各自獨立）。
3. **批次一律帶全額月費**。月中新生用「單獨開單」處理：自訂區間 → 按週數比例折算 ＝ 月費 × min(1, round(區間天數 ÷ 7) ÷ 4)，可再微調。
   （系統沒有記錄報名日期，月中生由行政開單時自行判斷，工具負責算比例。）

## 停課日曆

- 系統**預載台灣國定假日**（含連假；清單隨程式碼帶入未來年度，每年更新一次）。
- 後台可：**新增**自訂停課日（颱風假等，附名稱）、**刪除**任一天（該假日照常上課）。
- 只影響之後開的帳單；**已定案帳單凍結**，改日曆不回溯。

## 批次 → 帳單 → 繳款（三層帳本）

### 批次（BillingBatch）

- 欄位：種類（班級／個別輔導）、收費區間（個別輔導有「選月份」快捷帶入起訖）、狀態（草稿／已定案）。
- 建立三步驟：選種類 → 設區間 → **勾選班級／課程（預設全勾）** → 產生草稿。
- 草稿清單：每學生一列「學生｜班級（或課程）｜堂數｜單價｜金額｜備註」，**堂數與金額皆可直接改、可刪列**。
- **重疊偵測**：同學生 × 同班級（或同個別輔導報名）已有帳單、且區間與本批重疊（含部分重疊）→ 該列自動跳過，草稿下方列出跳過原因（例：「小明 × 週六班：已有 9/1～2/28 帳單，本批略過」）。部分重疊也是先跳過＋標示，缺的段落由行政用單獨開單補。
- **定案**（ConfirmModal 確認）：凍結所有明細 → 班級帳單**自動充值**（開一期 EnrollmentPeriod，堂數＝計費堂數）→ 推播通知家長。個別輔導定案不動月額度（額度本來就每月自動核發）。

### 帳單（Bill）

- 快照欄位（定案後不再重算）：區間、區間堂數、折抵堂數、計費堂數、單價（或月費與折算比例）、應繳金額、**上課日期清單＋停課日清單**、備註。
- 繳費狀態（由繳款推導）：未繳（紅）／部分繳（橘，顯示尚欠）／繳清（綠）。
- **單獨開單**：批次之外，選學生＋班級（或個別輔導）＋自訂區間，同一套計算引擎（含假日扣除、折抵、月費折算）。用途：一次預繳多季、月中入班新生。
- **退班結算**：已定案帳單上的動作。系統自動帶出「區間內實際上課堂數」（點名紀錄，扣堂語意同現有：請假、未報名不扣）→ 結算金額 ＝ 已上堂數 × 單價 → 行政確認後帳單金額改為結算金額、標記「已結算（退班）」＋備註，繳費狀態按新金額重算（顯示應追收或應退）。建議值可手動改。

### 繳款（Payment）

- 每張帳單可登記多筆：金額、繳費日期、方式（現金／轉帳）、備註、經手人。
- 自動計算已繳／尚欠；登記錯誤可刪除該筆。繳款總額不可超過應繳金額（超過擋下）。

## 帳單明細顯示

- **日期清單**（一律顯示，定案時凍結）：區間內每個上課日以「、」分隔，日期照全站慣例帶星期。
  - 正常上課日：一般字色。
  - 停課日：紅字＋刪除線＋假日名稱（例：~~9/27（六）教師節連假~~）。
- **折抵說明**（有折抵才顯示）：
  > 上期剩餘 5 堂｜折抵上限 2 堂 → 本期折抵 2 堂，其餘 3 堂保留至本期繼續使用
- **算式**：計費堂數 × 單價 ＝ 金額（月費帳單顯示級距與折算比例）。
- 行政端草稿／批次詳情、家長端帳單頁，三處同一份明細。

## 行政端 UI

- 導航新增「**收費**」。主頁三分頁：**批次列表／停課日曆／收費設定**。
- 批次列表：每批顯示種類、區間、狀態、總應收／已收／未收；按鈕「開新批次」「單獨開單」。
- **單獨開單的帳單**（不屬於任何批次）在批次列表下方獨立區塊列出，同樣顯示繳費狀態、可點列登記繳款與催繳。
- 批次詳情（定案後）：每列繳費狀態欄；點列開**繳款登記彈窗**；未繳清列有「催繳」按鈕；「匯出 Excel」（沿用 ExportExcelButton）。
- 收費設定分頁：英數級距表維護、折抵上限、**繳費資訊文字**（銀行帳戶等，自由文字）。
- 班級單價欄位放在**班級編輯彈窗**；學生覆寫價放在**報名管理**。

## 學生端（家長）UI

- 導航新增「**繳費**」頁，**唯讀**：
  - 頂部**繳費資訊卡**：「繳費方式：現金（櫃檯）／銀行轉帳」＋後台設定的銀行帳戶文字。
  - **待繳區**：每張未繳清帳單一張卡片（項目、區間、應繳、已繳／尚欠），點開看完整明細。
  - **繳費紀錄**：歷史帳單收合表格（預設 3 筆，展開全部），可點開明細與逐筆繳款紀錄。
- 手足帳號各自看各自的帳單。

## 通知（全部走 notifyUser 唯一入口）

1. **帳單定案**：定案彈窗二選一——「定案並立即通知全部家長」或「先定案，稍後再通知」。通知內容：每位家長一則「繳費通知：{學生} {項目} {區間} 應繳 {金額}」，點擊進繳費頁。
   - **分批通知**：批次詳情每列顯示通知狀態（未通知／已通知＋時間，存 `Bill.notifiedAt`）；列前有勾選框，可「通知勾選家長」或「一鍵通知所有未通知」；已通知的可重發。行政可依自己的節奏分批發送。
2. **繳款登記**：登記後推播「已收到繳費 {金額}」（部分繳附尚欠）——等同電子收據。
3. **催繳**：行政在批次詳情手動按，附尚欠金額。不做自動催繳。

## 資料模型（草案）

- `ClosedDay`：date（unique, UTC 日曆日）、name、source（NATIONAL｜CUSTOM）。
- `Class.feePerSession Int?`；`ClassEnrollment.feeOverride Int?`。
- `TutoringFeeTier`：name、sessionsPerWeek、monthlyFee、sortOrder；`TutoringEnrollment.feeTierId?`。
- `BillingSetting`：折抵上限、繳費資訊文字（單列或 key-value）。
- `BillingBatch`：kind（CLASS｜TUTORING）、periodStart、periodEnd、status（DRAFT｜FINALIZED）、finalizedAt。
- `Bill`：batchId?（單獨開單為 null）、studentId、classId? ／ tutoringEnrollmentId?、periodStart／End、sessionsTotal、deductedSessions、billedSessions、unitPrice／monthlyFee＋prorationRatio、amountDue、detail（JSON：日期清單、停課清單、折抵明細）、settledAsWithdrawal Boolean、note。
- `BillPayment`：billId、amount、paidOn、method（CASH｜TRANSFER）、note、createdById。
- 日期一律 UTC 日曆日儲存／比較，「今天」以台北判定（遵循全站 date conventions）。

## 邊界情況

- 定案後改停課日曆、單價、級距 → 舊帳單不變。
- 班級軟刪除：已開帳單保留可查；批次產生只含 active 班。
- 學生退班：帳單保留；先退班結算再退班。退班結算的堂數計算**僅適用班級帳單**；個別輔導帳單若需中途調整，走同一個入口直接修改金額＋備註（不帶堂數計算）。
- 草稿批次可整批刪除重開；已定案批次不可刪（帳單可個別退班結算調整）。
- 權限：收費管理 ADMIN only；學生端僅能查自己的帳單（手足切換各自隔離）。

## 測試重點

- 日期展開：跨月／跨年區間、假日落在上課日／非上課日、自訂停課日、刪除預載假日（照常上課）。
- 折抵：剩餘 0／1／2／5 堂各情境；充值後堂數餘額與帳單一致。
- 月費折算公式；批次全額；單獨開單折算。
- 重疊偵測：完全重疊、部分重疊、不同班不誤判。
- 退班結算：已繳全額（應退）、未繳（追收）、部分繳。
- 繳款：多筆加總、不可超繳、刪筆後餘額回復。
- 權限：非 ADMIN 打收費 API 全擋；學生互看擋。
